03 / 逐日行程

每天只安排一个重点，
给海风和意外留出时间。

晨间与夜间行程以步行、地铁和公交为主。抵达城市后的第一件事始终是寄存行李或入住，避免拖着行李在景区赶路。

09 / 15DAY 01

成都飞抵青岛，走进老城夜色

优先选成都天府至青岛胶东直飞，下午抵达后乘地铁进市南。入住后步行栈桥、天主教堂外观、中山路、劈柴院与信号山；晚餐控制在两人 ¥120 内。

住 / 青岛 01中山路地铁站周边

第一晚不住机场。老城步行方便，次日不需要换酒店。

09 / 16DAY 02

八大关到奥帆中心，一条免费的海岸日

八大关、第二海水浴场、太平角、五四广场、奥帆中心顺序步行加地铁。中午在香港中路附近解决，日落留给奥帆中心，避免额外购买游船项目。

住 / 青岛 02继续住中山路

减少搬行李；八大关往返用地铁与公交即可。

09 / 17DAY 03

崂山太清线一日，晚间整理行李

上午地铁到大河东，换乘景区观光车进太清游览区；17:00 前离园回市区。崂山 9 月处于旺季，必须在入园前 7 天实名预约，不把索道和额外项目计入基础预算。

住 / 青岛 03继续住中山路

次日从青岛北站出发，地铁 1 号线直达。

09 / 18DAY 04

高铁到威海，慢慢适应更安静的海

青岛北至威海二等座按 ¥96 / 人封顶。下午入住后游悦海公园、幸福门，夜间去韩乐坊吃饭。当天不安排刘公岛，给高铁延误和午休留余量。

住 / 威海 01旅游码头 / 市中心

第二天步行或短途公交到刘公岛旅游码头。

09 / 19DAY 05

刘公岛，半岛旅行里唯一的登岛日

上午乘往返船登刘公岛，成人票已含景区门票及船票 ¥122 / 人。下午回到市区后前往国际海水浴场、火炬八街或小石岛看日落，不再购买环岛游、潜艇与讲解等二次项目。

住 / 威海 02继续住市中心

次日退房后乘高铁离开，尽量订上午班次。

09 / 20DAY 06

威海到烟台，再到蓬莱

威海至烟台二等座按 ¥27 / 人封顶，再转大巴去蓬莱约 1.5 小时、¥25 / 人。下午只走蓬莱海滨、八仙雕塑与老北山外围；戚继光纪念馆免费，晚上早休息。

住 / 蓬莱 01蓬莱阁景区步行区

次日不用拖行李赶景点，退房后直接转去烟台港。

09 / 21DAY 07

蓬莱阁登高，夜航横渡渤海

上午入蓬莱阁，成人 ¥100 / 人；下午大巴返回烟台市区、转往烟台港。建议 20:30 前到港，选择 22:10 至 22:40 的夜班。订三等 A 舱，两人预算 ¥680，比四等多约 ¥120，但夜间休息明显更好。

住 / 船上烟台港 → 大连湾

带上外套、耳塞、洗漱包与充电宝；船上这一晚已替代酒店。

09 / 22DAY 08

清晨抵达大连，先寄存再游城

约 05:00 至 05:30 抵达。不要加钱早入住，先寄存行李；上午走中山广场、劳动公园，下午东港商务区、威尼斯水城、港东五街。晚间再办理入住，早到日保持轻量行程。

住 / 大连 01友好广场 / 青泥洼桥

近地铁 2 号线，去东港和机场都方便。

09 / 23DAY 09

滨海路慢走日，把大连留到最后

星海广场、跨海大桥观景、傅家庄、北大桥与渔人码头分段游览。中间用公交或一次短途网约车接驳，避免强行徒步全程。老虎滩五馆票两人需 ¥440，本预算方案不进入。

住 / 大连 02继续住友好广场

晚餐后整理托运和随身行李，次日直接返程。

09 / 24DAY 10

大连飞回成都

优先订中午或下午航班。地铁 2 号线或机场大巴前往周水子机场；两人返程机票、行李额度与选座总价不得超过 ¥2,000，超过则优先调整返程日期而不是挤占酒店与餐饮预算。

返程大连周水子 → 成都

提前 2.5 小时抵机场，保留夜船后的行程弹性。
